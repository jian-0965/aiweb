# BioGrow 技术设计

## 需求与创新目标

问题：学习者容易把阅读完成当成掌握，常见平台只显示完成率而不给出有依据的下一步。方案：将题目作答作为证据，以可解释概率模型为每个主题维护学习状态，连接可操作实验和复习任务。

应用层的组合设计：知识状态、前置关系、实验探究和错题复习共同参与闭环。BKT 是已有研究方法，不将算法本身声称为原创。原创部分为本作品的交互、内容、可视化与功能整合。

## 架构

纯浏览器应用，无服务端运行需求：内容与题库 → 题目选择 → 作答记录 → BKT 更新 → 路径推荐 → 下一次学习。数据落地于 localStorage，可手动导出。模块边界见 README。

## BKT 推断

令 p 为掌握概率，s 为失误概率，g 为猜测概率，t 为学习转移概率。

- 正确后验：`p(1-s) / [p(1-s) + (1-p)g]`
- 错误后验：`ps / [ps + (1-p)(1-g)]`
- 下一时刻掌握概率：`posterior + (1-posterior)t`

推断过程、参数和最近一次更新在界面可查。初始参数尚未拟合，不将后验百分比解释为考试分数。BKT 是统计隐藏状态模型；周边的计划、间隔安排为启发式逻辑。

## 教学设计

主题按有向无环前置关系组织：细胞为基础，膜运输衔接渗透，酶衔接光合与呼吸，最后连接生态系统。用户可以越级探索，系统建议而不封锁。学习目标有 10、20、30、45 分钟可选。内容时长为估计，不虚构实际学习时长。

练习先选择未做过的题，随后按最近作答时间及主题优先级排序。5 题诊断固定覆盖 5 个基础主题，每个主题优先未见题。单主题按难度选题，最多 4 题，允许少于 4 题。每个回答记录时间、选项、正确性、先验、后验和更新后概率，提供可审核时间线。

## 科学模型限制

渗透可视化展示水流方向，体积关系为 tanh 教学示意，不满足完整质量守恒动力学，不可用于预测真实细胞变化。酶温度响应为非对称经验曲线。光合作用用限制因子的饱和响应比较演示平台期，不宣称拟合真实植物数据。滑块改变表示独立实验条件。

## 测试策略

测试手算贝叶斯例子、重复观测的方向性、前置主题、复习到期、题库唯一性与引用、未见题优先、三类实验的边界和导入格式拒绝。部署后还应由用户在桌面与手机验证布局、键盘访问、下载与 JSON 导入。

## 后续研究路线

收集经同意的匿名学习序列；划分按学生隔离的训练/验证集；拟合 BKT 参数并评估正确率预测的 log-loss、校准度；与统一路径基线比较学习收益。若接入大模型，优先用于依据题库与概念卡片的苏格拉底式提示，保留依据、拒答与审查机制，不把模型输出直接视为标准答案。

## V1.1 教学与真题扩展

引导学习独立模块将每个主题展开为结构探索、分步解释、交互活动和自我讲解。结构图的节点可用鼠标或键盘激活；练习采用配对、排序与先预测后观察。学习完成状态存入可选 `learning` 字段，不直接影响 BKT。自我讲解只做关键词覆盖提示，不声称自动判定科学正确性。

题库合并 32 道原创题与 16 道有来源的高考转录。选题新增严格 difficulty 过滤：1 基础、2 进阶、3 高考综合。难度 3 是训练档位，不是各真题的实测难度标定。使用提示或概念卡片后，通过 assisted 标记保留答题记录但跳过 BKT 更新。

## V1.3 能量专题与错因自评

五节概念解释将 ATP 的能量耦联、酶的催化与变量控制、光反应和碳固定、两类呼吸途径、净光合与总光合串联。每节先写主观解释，保存后才展示参考思路和三点自查清单。自评不等于自动批改，不进入 BKT。

实验设计让学生选择自变量、因变量、保持不变的条件和可检验预测。选择符合单因素对照设计后展示既有 `simulate` 模型的四组示意结果，并可保存自己的结论。这里的数据不是生物实测，也不模拟重复测量、误差或统计显著性。错题原因由学生选取并记录在答题事件中，不声称从选项反推出真实认知原因。

存储继续使用 `biogrow.v1`，新 `energy` 字段和 `cause` 字段可选且导入时校验。旧档案可直接读取，主观题与模拟数据不改变掌握估计。

## V1.4 遗传规律专题

遗传模型由 `genetics-core.js` 中的纯函数生成等概率配子并两两组合；纯合位点保留重复配子，以维持准确的组合机会。单基因完全显性、不完全显性、双基因自由组合、X 连锁隐性和 ABO 共显性各有独立前提。双基因模型仅用于独立分配，不用于连锁位点；X 连锁模型按男女出生机会各半计算“下一胎患病男孩”，与“已知是男孩”条件下的概率区分。ABO 仅用一位点的三个常见等位基因示意，未模拟罕见血型或输血安全。

学习者先拼一格，再预测总体比例，展开组合表与表型分布。四个家系案例强调排除模型、证据不足时不定型；五道概率题涵盖条件样本空间与连锁例外。专题浏览、作答和提示保存在可选 `genetics` 本地字段，不会改变 BKT。既有遗传知识点仍偏 DNA 信息传递，相关高考题也限于该范围；专题没有伪称提供遗传规律高考原题。

## V1.5 能量全景图

`energy-map.js` 生成自包含 SVG，包含植物光反应、碳固定、有机物形成与自身呼吸，及人体以淀粉为例的消化、吸收、血液运输、糖酵解、有氧呼吸和 ATP 利用。节点通过事件代理显示短解释与思考题；同一 SVG 可由浏览器下载，步骤按钮为移动端和键盘提供替代入口。

图示明确光反应释放氧气的氧来自水，形成有机物所用的碳来自 CO₂；叶绿体中的 ATP/NADPH 主要服务碳固定，植物其他细胞活动仍依赖细胞呼吸。人体糖酵解与线粒体后续有氧过程分开表示，O₂ 从呼吸系统进入，CO₂、水和热为输出。教学图省略许多中间步骤，不做能量效率或产量预测。


## V1.6 成长报告

系统证据与自评分开呈现，15道选择题＋5道可选主观题。选择题与统计规则可在无模型时提供基础建议；主观文本通过服务端模型理解后才称AI规划。所有模型输出只映射到已存在课程和任务类型，日期和分钟预算由确定性排期约束。

学习数据保留于原有 `biogrow.v1`，新增可选 `growth` 字段，保持旧档案兼容。问卷草稿、提交时间、设置、当前与上一版计划都参与备份及导入校验。问卷无账号或姓名字段；模型只获取自评和聚合记录，不获取笔记全文。

部署迁移至Sites Vinext Worker，现有页面搬到 `public/`，静态入口仍为原有HTML和ES模块。服务端 `/api/growth-plan` 仅接受站点已认证同源POST；无配置返回503及机器可读状态，前端明确展示规则建议。结果验证失败、超时与供应商错误不会伪造AI成功。模型凭据待配置，未完成实际模型联调。
