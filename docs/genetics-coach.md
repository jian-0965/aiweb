# 遗传推理教练

入口：导航「遗传推理教练」或 `#coach`。

学生流程：输入题目（或上传图片转写）→ 校正题干与计算面板 → 明确确认 → 方向提示 → 拆解提示 → 完整核对 → 原创迁移练习 → 按结果安排 1/3 天后的复习。练习记录保存在当前浏览器，提示使用单独标记，不直接提高 BKT 掌握度。

## 实际实现

- `frontend/coach/`：严格 TypeScript，编译为 `public/coach/`；原站其他模块仍为 JavaScript。
- `server/coach-api.js`：Chat Completions function-calling 循环，最多 4 轮/8 次工具调用。模型可调用站内检索、已确认条件的精确遗传计算、当前学习统计和原创练习选择。轨迹区分模型调用与流程执行；并非 MCP 服务。
- `server/coach-knowledge.js`：12 篇原创教学笔记，中文字符与双字词 BM25 检索。回答携带实际检索的引用，引用不存在时拒绝 AI 输出并回退。这里是词项检索 RAG，不是向量数据库。
- `server/coach-tools.js`：白名单模型，确定性枚举配子与子代，返回精确分数。覆盖单基因完全显性、不完全显性、自由组合、X 连锁隐性、ABO；不能推广到连锁、多胎或现实医疗判断。
- `server/coach-practice.js`：10 道原创迁移题，独立于示例题。判分由服务端题库完成，出题响应不带答案。
- 图片压缩到最长边 1400px 并经 Canvas 重编码，用户点击识别才发送给模型；服务端不持久保存图片。模型服务自身的留存政策另依服务商约定。识别结果须用户校正，不自动猜亲本。

## 配置

沿用服务端 `MODEL_API_KEY`、`MODEL_BASE_URL`、`MODEL_NAME`；可选 `COACH_MODEL_NAME` 指定支持 function calling 的模型，可选 `VISION_MODEL_NAME` 指定支持图片输入的模型。所有密钥只在服务端使用。

缺少配置、上游失败、超过调用预算或引用校验失败：返回 `source: rules`，前端明确标为基础引导。图片失败时提示手动输入。模型服务是否免费取决于账户额度和服务商，不作永久免费承诺。

## 安全与边界

接口要求托管身份，检查请求来源、JSON 类型、体积、字段枚举；按用户/接口做进程内限流（不是跨实例全局额度）。工具不能执行任意代码或改写已确认亲本。文本输出转义；历史仅包含当前题目的提示，发送学习统计不包含私人笔记。提示词隔离不能绝对阻止模型出错，重要结论须结合条件与工具核对。

复习记录限 100 条、遗传答题记录限 5000 条，可随站内学习档案导入导出。该模块不提供跨设备账号同步。

## 验证

`npm test` 自动先编译教练前端。测试覆盖五类精确计算、条件分母、6 条人工检索样例、真实协议形状的模拟工具调用、非法工具/引用、循环预算、授权/来源/体积限制、模拟图片转写与确认、题库判分与复习记录校验。检索样例是小规模回归检查，不代表对所有试题的检索质量，也不是学习效果实验。

运行时 API 密钥不可读，自动化模型测试使用模拟响应；真实服务的可用性需另以部署后的调用结果判断。
