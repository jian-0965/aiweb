# 6 分钟演示流程（录屏提纲）

- 0:00–0:40：说明赛道 5，介绍“看过不等于学会”的问题与目标人群。
- 0:40–1:40：打开新学习档案，展示没有虚构成绩；完成 5 题诊断，有意答错一题观察解释。
- 1:40–2:30：查看学习路径和 AI 推断依据，展示先验、后验、学习转移、前置知识和新排序。
- 2:30–3:30：进入渗透实验，先预测高渗情况下水流方向，调节外液浓度，记录两组条件。说明模型为教学示意。
- 3:30–4:20：完成渗透主题练习，展示概率更新、错题回顾与概念卡片。
- 4:20–5:10：写一条笔记，查看成长报告与真实作答时间线，导出学习档案。
- 5:10–6:00：展示技术模块和测试。明确 BKT 为已有算法，原创点为闭环交互整合；参数未拟合、当前无 LLM、下一步做真实效果验证。

正式视频要求：普通话，5–8 分钟，MP4，分辨率至少 1080p。此文件是录屏提纲，不是已录制视频。
